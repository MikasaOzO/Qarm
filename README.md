# Robotic Pick and Place for Fruit Sorting

This project integrates Python-based vision detection with a Simulink control system to perform automated fruit sorting using the Quanser QArm.

## System Overview

The system consists of three main parts:

1. Python vision module (YOLO + RealSense)
2. Simulink control model
3. QArm hardware execution

Detection results are written to a JSON file and read by Simulink during each control cycle.

## Requirements

- Python 3.x
- MATLAB / Simulink
- Required Python libraries:
  - `ultralytics` (YOLO)
  - `pyrealsense2`
  - `opencv-python`
  - `numpy`

## How to Run

### Step 1: Start vision detection

Run the Python script:

```bash
python Detected_Object_YOLO_2.py
```

This will:

- Start the RealSense camera
- Detect fruits: banana, strawberry, and tomato
- Output detection results to:

```text
vision_result.json
```

### Step 2: Open Simulink model

Open:

```text
PickAndPlace_Hardware.slx
```

Make sure:

- `read_vision_result.m` is in the same folder
- `vision_result.json` is being updated

### Step 3: Run the control system

Start the simulation in Simulink.

The system will:

- Read detection results from JSON
- Convert camera coordinates to robot coordinates
- Execute pick-and-place using the state machine

### Step 4: Optional manual control

Run:

```text
QArm_Control_Panel.m
```

This allows:

- Manual control of robot joints
- Switching between manual and automatic modes

## Notes

- The robot uses a top-down approach to avoid collisions.
- Grasp height is fixed to reduce depth noise effects.
- Coordinate transformation is based on calibrated linear mapping.

## File Description

| File | Description |
|---|---|
| `Detected_Object_YOLO_2.py` | Vision detection using YOLO and camera input. |
| `PickAndPlace_Hardware.slx` | Main Simulink control model. |
| `read_vision_result.m` | Reads JSON detection results. |
| `QArm_Control_Panel.m` | Manual control interface. |
| `install_manual_control.m` | Setup script for manual control. |
| `vision_result.json` | Communication file, auto-generated by the vision module. |
